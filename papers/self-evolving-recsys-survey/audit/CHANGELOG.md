the change is listed here with the commit that made it. Rows that first appear in a version are listed as added.

adjudications (PILOT correction, DMRL and AgentX duration) are recorded in `evidence-online-gates.md`.

for example, AgentLTV C3 `NS` -> `N` applies the codebook rule that a loop selecting on its reported test data (C2 `test`)
does not use test data once (see `evidence-part2.md`).
