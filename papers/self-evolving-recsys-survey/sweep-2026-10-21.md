# Papers missing from recforge/docs/related-work.md

Checked 2026-10-21 against `docs/related-work.md` (87 arXiv IDs).

How this list was made:
- arXiv API full-text abstract queries (about 30 phrasings: self-evolving / self-improving / autonomous / agentic / auto-research / harness / coding agent / feature engineering / AutoML / semantic ID / evolution, each combined with recommend / CTR / ranking).
- Web searches (Google-style phrasing, AlphaEvolve/OpenEvolve, company names in English and Chinese).
- The bibliographies of RecHarness 2607.29241, EvoRec 2606.28368, AgentX-Model 2609.30001, RecEvolve 2609.01622 and the roadmap 2607.04433, read from the arXiv HTML.

Verification and tags:
- Every entry's title, authors, date and ID come from the arXiv API record (the abs metadata). Only abstracts were read, so the descriptions summarize abstracts.
- **Code** is listed only when the GitHub API confirmed the repository exists. The license is the one GitHub reports.
- **official?** means the owner is plausible but has not been confirmed as the authors.
- Affiliations are given only when the abstract names them.
